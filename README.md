# Recycle Negotiate Sell (RNS)

Recycle Negotiate Sell (RNS) is a Django-based web application designed for college students to promote sustainable practices and ease the exchange of used items. The platform allows senior students to list their used items for sale at affordable rates, making it easier for juniors to purchase these items. The project encourages recycling and reuse within the college community.

---

## Features

### User Roles:
- **Seniors (Sellers):**
  - List items for sale by providing details like name, description, price, condition, and images.
  - Organize items into categories and link them to specific brands.

- **Juniors (Buyers):**
  - Browse items based on categories, brands, or search criteria.
  - View detailed product information before making a purchase decision.

### Core Functionalities:
- **User Authentication:**
  - Secure login and registration system using Django's `auth` framework.
  - Support for different user roles.

- **Product Management:**
  - Create, update, and delete product listings via the admin interface.
  - Add multiple images for products.
  - Automatic slug generation for URL-friendly product names.

- **Categorization:**
  - Products can be grouped by categories and brands to simplify navigation.

- **Responsive Design:**
  - Fully responsive user interface for accessibility on desktops, tablets, and mobile devices.
